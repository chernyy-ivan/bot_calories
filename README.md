# 🍏 Calorie & Water Tracker Bot

Профессиональный асинхронный Telegram-бот для контроля питания, водного баланса и ежедневной активности. Проект разработан на базе фреймворка **Aiogram ** и использует архитектуру конечных автоматов (FSM) для пошагового взаимодействия с пользователем.

---

## 🚀 Основной функционал

*   **👤 Индивидуальный профиль:** Расчет суточных норм калорий и воды на основе анкетирования пользователя (возраст, рост, текущий и целевой вес).
*   **💧 Дневник воды:** Добавление выпитого объема через фиксированные инлайн-кнопки (+250 мл, +500 мл) или ввод кастомного значения.
*   **🍎 Контроль питания:** Логирование съеденных продуктов с автоматическим подсчетом калорийности и выводом остатка до выполнения суточной нормы.
*   **🏃‍♂️ Трекинг активности:** Учет пройденных шагов за день с валидацией вводимых данных.
*   **📊 Контроль веса:** Запись динамики веса с защитой от некорректного ввода (обработка дробных чисел через точку/запятую).

---

## 🛠 Технологический стек

*   **Язык разработки:** Python 3.10+
*   **Фреймворк:** [Aiogram 3.x](https://github.com/aiogram/aiogram) (Asynchronous Telegram Bot API)
*   **База данных:** SQLite3 (хранение профилей и ежедневных логов активности)
*   **Управление конфигурацией:** Python-dotenv (безопасное хранение токенов в `.env`)
*   **State Management:** AIogram FSM (Finite State Machine) для пошаговых сценариев

⚙️ Локальное развертывание
1. Клонирование репозитория
Bash

git clone [https://github.com/your_username/bot_calories.git](https://github.com/your_username/bot_calories.git)
cd bot_calories

2. Настройка виртуального окружения
Bash

python3 -m venv venv
source venv/bin/activate

3. Установка зависимостей
Bash

pip install -r requirements.txt

4. Конфигурация переменных окружения

Создайте файл .env в корневой директории проекта и укажите ваш токен бота:
Фрагмент от код

BOT_TOKEN=your_telegram_bot_token_here

5. Запуск приложения
Bash

python3 main.py

📝 Разработка и архитектура

    Модульность обработки событий: Каждый логический блок (вода, еда, шаги) вынесен в отдельный изолированный роутер внутри пакета handlers. Это разгружает main.py и позволяет легко масштабировать проект.

    Валидация данных: Реализована строгая проверка типов данных при заполнении анкеты и вводе числовых метрик, что полностью исключает падение бота из-за некорректного ввода пользователя.

    UX/UI интерфейс: Управление полностью переведено на InlineKeyboardBuilder с динамическим обновлением текста сообщений (edit_text), что избавляет чат от лишнего спама сообщениями.

## 📁 Структура проекта

```text
bot_calories/
│
├── data/                   # Папка для хранения файлов базы данных SQLite
├── handlers/               # Модуль обработчиков команд и событий (Роутеры)
│   ├── __init__.py         # Главный роутер, объединяющий подмодули
│   ├── activity.py         # Хендлеры логирования шагов
│   ├── common.py           # Команда /start, анкета и отмена состояний
│   ├── food.py             # Дневник питания (подсчет калорий)
│   ├── notifications.py    # Фоновые задачи и периодические напоминания
│   ├── water.py            # Учет выпитой воды
│   └── weight.py           # Просмотр профиля и обновление веса
│
├── .env                    # Локальный файл с приватными переменными окружения
├── .gitignore              # Исключения для Git (venv, .env, __pycache__)
├── database.py             # Модуль для работы с БД (SQL-запросы, инициализация таблиц)
├── keyboards.py            # Генерация Inline-клавиатур для меню и разделов
├── main.py                 # Главная точка входа, запуск асинхронного polling бота
├── requirements.txt        # Список зависимостей проекта
└── states.py               # Машины состояний (FSM) для пошаговых сценариев
